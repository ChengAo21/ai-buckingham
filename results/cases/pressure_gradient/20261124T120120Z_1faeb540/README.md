# Skin friction under pressure gradients

[View results](https://chengao21.github.io/ai-buckingham/cards/pressure_gradient.html) · [Reproduce](https://chengao21.github.io/ai-buckingham/cards/pressure_gradient.html#reproduce) · [Notebook](../../../../notebooks/cases/pressure_gradient.ipynb)

From the repository root, configure the model services in [`.env.example`](../../../../.env.example) and run:

```bash
ai-buckingham pressure_gradient
```

Open `result.html` in the new `generated/cases/pressure_gradient/<run_id>/` directory. The notebook also generates cards from the included result using local files.

| Contents | Files |
|---|---|
| Figures in PNG, PDF and SVG | `plots/` |
| Coordinates and numerical tables | `tables/` |
| Input data and numerical settings | `resolved_config.json` |
| Complete state | `state.json` |
| Stage records and optimizer history | `evidence/` |
| Original system output | `report.html` |
